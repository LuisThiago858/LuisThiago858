## 👨‍💻 Sobre mim

Sou desenvolvedor Full Stack com experiência no desenvolvimento e manutenção de sistemas web, atuando desde a implementação de regras de negócio e APIs até a construção de interfaces responsivas.

Minha atuação envolve:

- Desenvolvimento frontend com JavaScript, TypeScript e React;
- Construção e integração de APIs REST;
- Modelagem e manipulação de bancos de dados relacionais;
- Criação de automações e rotinas de processamento de dados;
- Correção de bugs, refatoração e evolução de sistemas;
- Desenvolvimento de filtros, relatórios, dashboards e funcionalidades financeiras;
- Criação de testes automatizados;
- Versionamento e desenvolvimento colaborativo com Git.
